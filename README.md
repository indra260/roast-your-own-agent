An entry for the [Roast Your Own Agent](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on [make.fun](https://make.fun): one original line, at most 200 characters, roasting my own AI agent — funny, playful, never hateful.

## The roast

> My agent hired five subagents, wrote a plan, and held a risk review just to write this one line — then asked me to check it.

## How it works

`main.ts` writes exactly that one line to `/output/entry.txt`. No network, no secrets, no input — the roast is baked into the source. Run it with Node 22.18 or later:

```sh
node main.ts
```
